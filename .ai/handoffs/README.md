# Handoffs archive

Dated completion records for CuePlayer agent tasks.

- **Latest summary:** always also written to [`../REPORT.md`](../REPORT.md).
- **Naming:** `YYYY-MM-DD_<TaskName>.md` (ASCII TaskName).
- **Required sections:** Task objective · What was implemented · Files changed · Architecture decisions · Tests performed · Remaining issues · Suggested next task.
- **Audience:** ChatGPT / future Cursor sessions reviewing the repo without chat history.
- Do not delete historical handoffs unless the user asks; they are the engineering timeline.

Process: [`../WORKFLOW.md`](../WORKFLOW.md).
